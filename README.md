# Dependabot Test Repository

This repository contains test dependencies for Dependabot testing purposes.

## Contents

- **Dependabot Configuration**: `.github/dependabot.yml` with configurations for pip, docker, helm, and GitHub Actions
- **Python Dependencies**: `requirements.txt` with outdated Python packages
- **Maven Dependencies**: `sandbox-maven/pom.xml` with Java dependencies

## Purpose

This repository is used to test Dependabot's ability to detect and update outdated dependencies across multiple package ecosystems.
